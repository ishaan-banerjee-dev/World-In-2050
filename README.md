# World in 2050

A website predicting what the world could look like in 2050, created for a school competition.

## About

**World in 2050** is a school project exploring how different aspects of life and the world may change by the year 2050. The website presents predictions and ideas about the future through an interactive web experience.

## Features

* Futuristic 2050-themed design
* Predictions about the future
* Multiple sections exploring different aspects of the future
* Responsive navigation using HTML and CSS
* Created for an inter-school competition

## Technologies Used

* HTML
* CSS
* Font Awesome

## Project

This project was created for an inter-school competition as a web-based presentation of our vision of the world in 2050.
